GoReleaser v2.17.1 OSS supports `checksum.extra_files` for tracked `install.sh` (`https://raw.githubusercontent.com/goreleaser/goreleaser/v2.17.1/www/static/schema.json#L890-L919`; `https://goreleaser.com/customization/package/checksum/`). Use `checksum.extra_files: [{glob: ./install.sh}]`; only `templated_extra_files` is Pro. The checksum implementation adds matched files only to its local checksum artifact list, not to `ctx.Artifacts` (`https://github.com/goreleaser/goreleaser/blob/v2.17.1/internal/pipe/checksums/checksums.go#L183-L213`). Therefore this repository's manual staging path must separately copy the unchanged tracked script into `dist/release-assets/`; it should not regenerate or append the checksum manifest afterward. If GoReleaser itself later owns release publishing, also use `release.extra_files: [{glob: ./install.sh}]` (`https://goreleaser.com/customization/release/`).
